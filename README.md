# Shadow Reckoning — Play & Download

Play: https://dr-kaya.github.io/shadow-reckoning-play/

Download the standalone Mac app from [Releases](https://github.com/Dr-Kaya/shadow-reckoning-play/releases/latest).

The browser edition runs the original Python combat, renderer and input handlers through Pyodide, with Canvas and Web Audio adapters. No account or installation is needed. The first launch downloads the runtime and game artwork. Internet is required for the browser edition; the Mac app runs offline.

Keyboard recommended. Arcade vs CPU, training, and local two-player modes are included. Local duel uses one keyboard; internet multiplayer is not included.

## Mac installation
1. Download Shadow-Reckoning-Mac.zip from Releases and unzip it.
2. Drag Shadow Reckoning.app to Applications and open it.
3. If macOS blocks this locally signed, non-notarized app, use System Settings → Privacy & Security → Open Anyway after attempting to open it.

Requires macOS 11 or newer; includes Apple Silicon and Intel runtimes. Python is bundled.

## Browser runtime
Uses Pyodide 0.28.3 from the official jsDelivr distribution. Pyodide is distributed under MPL-2.0; see https://github.com/pyodide/pyodide for licenses.
